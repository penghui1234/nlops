支撑技术栈

① 入口层

飞书 Custom App + 异步两段式 (Lambda 自调用满足 3s ack)

② AI 引擎

AWS DevOps Agent (跨源关联) · Bedrock Nova Pro (内容增强)

③ 渲染层

Lambda + Jinja2 + marked.js + ECharts + Mermaid · S3 永久 URL

④ 通知层

飞书 Custom Robot Webhook (群消息卡片) + Amazon SES (HTML 邮件)
